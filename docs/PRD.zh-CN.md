## 产品一句话

Clove 是给摄影师在 iPhone、iPad 和 iPhone Duo 上用的原位选片应用。你对着 SD 卡、外置硬盘或 Files 里的文件夹看图、打星、打色标、标拒绝。星级和色标写进 XMP 旁路文件。拒绝片在你确认后被移进 `_Rejected` 文件夹，不会被删除。原片内容从不修改。回家后用 Lightroom、Capture One 或 Photo Mechanic 接着做，它们只会看到留下来的照片和你打的星级、色标。

它不是相册管理器，不是云备份，也不是社交或调色工具。对标对象是第三方应用 [AI Photo Culling — PhotoPicker](https://apps.apple.com/us/app/ai-photo-culling-photopicker/id661470243)，不是系统自带的照片选择器。

策略：手动选片体验和 XMP 写得准，优先于 AI。首发的智能功能只做相似组，而且可以关掉。

## 给谁用，用来干什么

目标用户是要在外出或回程路上完成第一轮挑选的摄影师，主要拍 RAW 或 RAW+JPG。他们把照片放在 SD 卡、外置 SSD 或 Files 能打开的文件夹里，需要尽快浏览、检查是否合焦，然后留下能被桌面软件读懂的标记。

主要工作：

1. 打开或重新打开一个文件夹（含 `DCIM/100XXXXX` 这类子目录），而不是把照片导入应用或系统图库。
2. 在网格里快刷，进入大图查焦。
3. 用手势、按钮或键盘打星、打色标、标拒绝。
4. 对连拍按组挑：组内对比，留下最好的一两张，其余拒绝。
5. 一键把拒绝片移进 `_Rejected` 文件夹。
6. 在 Lightroom、Capture One 或 Photo Mechanic 里读到同样的星级和色标，继续后期。

## 主路径

打开文件夹或从「最近打开」重开 → 网格浏览、筛选、排序 → 进入详情查焦并翻图 → 打星、色标或拒绝，写入 XMP → 按相似组挑连拍 → 执行「整理拒绝片」 → 离开后重新打开，标记还在，原片内容没有被改动。

| --- | --- |
| P0-01 | 打开与扫描：用系统文件选择器打开 SD 读卡器、外置硬盘或 Files 中的文件夹，递归扫描所有子目录，跳过拒绝片文件夹。扫描 JPEG、HEIC 和系统能预览的主流 RAW。同名的 RAW 与 JPG 合成一项。不把照片拷进应用自己的图库。 |

| P0-03 | 网格：缩略图优先使用文件里已有的嵌入预览，滚动流畅优先于立刻解码完整 RAW。排序默认按拍摄时间，可改为按文件名。筛选：全部、未标记、拒绝、N 星及以上。 |
| P0-04 | 详情：全宽大图、双指缩放和双击缩放到 100% 查焦、左右翻图、底片条，以及始终可见的当前标记。 |
| P0-05 | 标记：星级 0 到 5、色标、拒绝。拒绝不是删除。提供撤销。 |
| P0-06 | 手势与键盘：上滑按幅度打星，下滑拒绝；可设置启用哪些星级；外接键盘快捷键；打完标记后自动前进。 |
| P0-07 | XMP 读写与互操作：打开目录时读出已有 XMP。RAW 只写旁路文件，RAW+JPG 共用一份。尽量保全其他软件写下的未知信息。Lightroom、Capture One、Photo Mechanic 必须能读 Clove 写下的星级和色标。拒绝写在 Clove 自己的字段里，不对外承诺。单独的 JPEG、HEIC、DNG 可选写入文件内元数据，默认关闭。 |

| P0-09 | 网格长按进入多选，再批量写入星级、色标或拒绝。 |

| P0-12 | 组内选片：同步缩放对比、逐步淘汰、「保留这张，其余拒绝」和「保留已打星的，其余拒绝」。这两个操作永远不会拒绝已有星级或色标的照片。 |
| P0-13 | iPhone 与 iPad 的单图选片闭环同时交付。iPad 双图对比不做首发。 |
| P0-14 | iPhone Duo：外屏按紧凑布局，内屏默认并排显示网格和详情，半折时控件不得跨过折缝。展开、折叠或改变窗口大小时，当前目录、当前照片、筛选、选择和写入状态保持连续。叠加模式和半折专属布局推到 1.1。 |
| P0-15 | 外观使用系统组件，并同时提供浅色和深色，跟随系统外观。星级用系统橙，拒绝用系统红。色标跟随 Lightroom 的颜色含义。 |

## 首发明确不做

- Pick 旗（由星级取代）
- 系统照片图库入口（主入口或次要入口），以及「选一批照片进入临时会话、不写 XMP」的流程
- 把收藏或标记写回系统照片图库
- 相册管理、关键词管理、云备份、CloudKit、备份或同步向导
- 社交、分享流
- 打开或写回 Lightroom Classic catalog
- 自建目录，或把已选照片连同 XMP 拷到新文件夹（可作后续优先项，但不在首发）
- 删除原片、导出成片、视频主流程。把拒绝片移进 `_Rejected` 不是删除。
- 双图对比（已推迟）
- 调色、自动对焦点叠加
- AI 推荐最佳张、低质与糊片建议（推到 1.1）
- 手动拆分或合并相似组、用户自建组（拆分推到 1.1）
- 分组灵敏度设置
- Duo 叠加模式、Duo 半折专属布局（推到 1.1）
- 闭眼和表情分析、自然语言选片、联网云端 AI、任何由 AI 自动写入或覆盖标记的功能
- 自研 RAW 解码或 demosaic

## 各屏与状态

以下行为以产品与 UI 结论及本次修订为准。Figma 旧稿不采用，新概念稿按本节行为重新设计。

### 入口：打开与最近打开

- 主操作是「打开文件夹…」，走 Files / SD / 外置盘。
- 「最近打开」列出路径摘要、介质类型、张数、上次时间。点一项即用已记住的位置重开。
- 不提供系统照片图库入口。
- 稿面有搜索框。产品定稿没有单独锁定搜索最近打开的行为，不列为 P0。

### 扫描范围

- 递归扫描打开目录下的所有子目录。SD 卡的 `DCIM/100XXXXX`、`101XXXXX` 等目录合在一起显示。
- 跳过拒绝片文件夹（默认 `_Rejected`）。
- 同一目录下、文件名去掉扩展名后相同的 RAW 和 JPG 合成一项。网格里只占一格，以 RAW 为主，标记同时作用于两者。
- 打不开或不支持的文件，单独显示可见状态，不能用空白图冒充已经加载。

### 网格

- iPhone：三列。iPad：五列，左侧栏用于导航和筛选。
- 单元格叠加拒绝旗、星级、色点。RAW+JPG 配对有角标提示。
- 排序：默认按拍摄时间（读到亚秒），可改为按文件名。
- 顶部筛选：全部、未标记、拒绝、N 星及以上。
- 相似组的显示方式：
  - 「展开」（默认）：显示每一张，同组照片用蓝框圈在一起，标出张数。
  - 「折叠」：每组只显示一格封面加张数，点进去就是组视图。
  - 默认展开的原因：分组在后台逐步细化，折叠视图的格子会增减。无论哪种方式，分组细化都不能让用户正在看的那张照片位置跳走。
- 从网格可进入详情，也可进入相似组。
- 长按进入多选，再批量写入。
- 网格里不设双击操作，以免拖慢单击进入详情。

### 详情与标记

- 全宽预览。双指缩放查焦。双击画面中部，以点按处为中心放大到 100%，再双击回到全图。
- 左右边缘点按翻到上一张或下一张，放大时同样可用。边缘区域只识别单击，不等待双击，翻图不延迟。
- 当前标记必须一眼能看到，不能被手指挡住。详情使用顶部标记提示（星级、拒绝、色标）。iPad 使用右侧标记轨。这是为了避开竞品里「底栏状态被手挡住」的问题。
- 底片条标出当前张，可横滑跳转。
- 稿面另有文件名一类信息。具体展示哪些拍摄参数未锁定，不列为 P0。

标记规则：

| 控件 | 行为 |
| --- | --- |
| 星级 0 到 5 | 在星级条上点选某一级，再点同一级清零。只显示已启用的星级。 |
| 色标 | 默认红、黄、绿、蓝、紫，外加清除。设置里可开启扩展色（橙、粉，对应 Capture One）。写入 XMP 时使用固定英文名，不随系统语言变化。 |
| 拒绝 | 单独的开关。与星级互不影响：标拒绝时原有星级保留。拒绝不等于删除。 |
| 撤销 | 接入系统撤销机制：工具栏撤销按钮、外接键盘 ⌘Z、iOS 三指撤销手势都可用。自动前进之后撤销，画面回到被撤销的那一张。 |
| 保存状态 | 「写入中…」「已写入」「写入失败」。失败后提供重试。只有确认成功才能显示「已写入」。 |

### 多选批量写入

在网格长按进入多选，对选中的照片一次写入星级、色标或拒绝。成功与失败按张计算。部分成功时，已写上的保持已写上，失败的保持未写入，并允许只重试失败的那些。

### 手势与键盘

详情页手势：

| 状态 | 操作 | 效果 |
| --- | --- | --- |
| 全图 | 上滑（按幅度） | 打星。若该张已拒绝，同时取消拒绝。 |
| 全图 | 下滑 | 拒绝 |
| 全图 | 左右滑、边缘点按 | 翻图 |
| 全图 | 双击画面中部 | 以点按处为中心放大到 100% |
| 放大 | 单指拖动 | 平移画面。上下滑打标在放大时停用。 |
| 放大 | 边缘点按 | 翻图 |
| 放大 | 双击 | 回到全图 |
| 任意 | 双指缩放 | 缩放 |
| 任意 | 三指系统手势、⌘Z | 撤销 |

上滑按幅度打星：

- 每档对应一段固定的滑动距离（初值约 60pt，待实测调整），不按屏幕高度比例分，iPhone 和 iPad 手感一致。
- 滑动时在手指附近实时显示当前星级，每跨过一档给一次轻触觉反馈。往回滑可以降档。
- 以松手位置为准，不看滑动速度。轻甩一下就是最低一档。
- 松手前滑回起点，什么都不写。
- 手势不会清零星级。清零用星级条或键盘 `0`。

启用哪些星级（设置）：

- 用户选择允许使用的星级，默认 1 到 5 全部启用。
- 滑动的各档按顺序对应已启用的星级。例如只启用 1 到 3 星，就只有三档；只启用 1、3、5 星，一档是 1 星，两档是 3 星。
- 星级条和键盘也只接受已启用的星级。
- 这个设置只影响录入，不影响显示和筛选。其他软件已写下的 4 星、5 星照常显示，不会被改写。

外接键盘（iPad 优先，iPhone 接上键盘时同样生效）：

| 键 | 效果 |
| --- | --- |
| `0` 到 `5` | 打星（`0` 清零） |
| `6` `7` `8` `9` | 红、黄、绿、蓝色标（与 Lightroom 一致） |
| `↑` | 升到下一个已启用的星级 |
| `↓` | 拒绝 |
| `←` `→` | 翻图 |
| `⌘Z` | 撤销 |

自动前进（设置）：

- 打完标记后：停在当前张 / 下一张（默认）/ 下一张未标记的。
- 触发前进的标记：星级和拒绝默认触发，色标默认不触发。
- 打完后先停约 0.3 秒，让用户看到标记已生效，再前进。
- 在组视图里，自动前进到组内下一张待定的照片。组完成后的行为见「组内选片」。

手势相关设置：手势总开关、启用哪些星级、自动前进、触发前进的标记、双击行为（缩放（默认）/ 关闭）、翻图时保持缩放（组内默认开，普通详情默认关）。

### 相似组

首发智能功能只有相似组，目标是把连拍和重复构图归在一起。它只帮用户分组，不替用户写任何标记。

分组方式：

1. 按机身分开（机型加序列号），再按拍摄时间排序，读到亚秒。两台机身交替拍的照片不会混在一组。
2. 按时间间隔切段：相邻两张间隔小于阈值的归入同一段。阈值初值约 2 秒，需用真实样本校准，不是首发承诺。这一步只读 EXIF，打开目录后很快就能先显示出来。
3. 段内按画面相似度再切：在设备上对嵌入预览计算图像特征，相邻两张差别大就断开（比如中途换了主体）。这一步在后台运行，完成后细化分组。

规则：

- 少于 2 张的不算一组。没有拍摄时间的文件不参与分组。
- 分组结果只缓存在 Clove 里，不写进 XMP。
- 界面显示分析进度或「已分析」。「再跑一次」始终可以点。
- 用户可以关掉相似组。关掉后入口和网格蓝框都隐藏，打开、浏览和手动打标不受影响。
- 不提供分组灵敏度设置，先用实测校准过的默认值。
- 不对分组准确率做任何数字承诺。

### 组内选片

一组连拍可能有几十张，区别只在焦点、表情和动作瞬间。组视图围绕「对比细节、缩小范围、一键收尾」设计。

布局：

- iPhone：上方大图，下方本组底片条。
- iPad 和 Duo 内屏：大图加侧栏组内网格。
- 每张都显示星级或拒绝状态。顶部显示「待定 N / 共 M」。待定指既没有星级也没有拒绝的照片。

对比与淘汰：

- 同步缩放：在组内放大到某个位置后，翻到下一张时保持同样的缩放倍数和位置。组内默认开启。
- 被拒绝的照片在底片条上变暗。「只看待定」开关打开后，翻图跳过已拒绝和已打星的照片。
- 打完标记后自动前进到组内下一张待定的照片。

一键收尾：

| 操作 | 效果 |
| --- | --- |
| 保留这张，其余拒绝 | 当前张如果还没有星级，打上已启用星级中最低的一档；组内其余未标记的照片标为拒绝。 |
| 保留已打星的，其余拒绝 | 组内已打星的保持不变；其余未标记的照片标为拒绝。组内没有已打星的照片时不可用。 |

- 已有星级或色标的照片永远不会被这两个操作拒绝。
- 这两个操作按批量写入的规则处理成功与失败，并且可以撤销。

组完成：

- 定义：组内每张都已打星或已拒绝，或者用户执行了一键收尾。
- 设置「组完成后」：停在本组 / 自动进入下一组（默认）。跳到下一组时跳过已完成的组。

### 整理拒绝片

拒绝只服务于选片。整理之后，桌面软件里只剩留下的照片，不需要知道哪些被拒绝过。

- 触发：用户手动点「整理拒绝片」，不自动执行。可以在目录内任意时候执行。
- 确认：弹出确认，写明要移动多少张、包含配对的 JPG 和 XMP、原片不会被删除。
- 目标：打开目录下的 `_Rejected/`，文件夹名可在设置里修改。保留原来的子目录结构，例如 `DCIM/100XXXXX/IMG_0001.CR3` 移到 `_Rejected/DCIM/100XXXXX/IMG_0001.CR3`。
- 一起移动：RAW、配对的 JPG、对应的 XMP。
- 只在同一个卷上做移动，不做「复制再删除」。
- 目标位置已有同名文件时加后缀，绝不覆盖。
- 按张计算成功与失败。部分失败时，已移动的保持已移动，失败的留在原处，可以只重试失败的。
- 只读位置不能整理，沿用「只能看」的提示。
- 移走后，这些照片从网格消失，之后扫描也跳过 `_Rejected`。
- 恢复：用户把文件移回原处即可。XMP 里仍记着拒绝，回到 Clove 后照常显示为拒绝。应用内的「还原」不做首发。
- 设置里可以关闭整理功能。关闭后拒绝仍可用于筛选，只是不提供移动。

## 标记如何落盘

对用户来说，磁盘上的 XMP 才是标记的事实来源。界面上的「已写入」只能表示这件事已经在磁盘上完成。

1. 打开目录时先读已有 XMP，再显示星级、色标和拒绝。
2. 原片的图像内容永不修改。默认只写 XMP 旁路文件。
3. 旁路文件按「同名、换扩展名」命名，例如 `IMG_0001.CR3` 对应 `IMG_0001.xmp`。RAW+JPG 配对共用这一份。具体命名需与三家软件实测确认。
4. 星级写入标准星级字段，色标写入标准色标字段。
5. 拒绝写在 Clove 自己的 XMP 字段里，其他软件会忽略它。设置里可选「拒绝时同时写 Rating −1」（供 Bridge 一类软件识别），默认关闭。
6. 单独的 JPEG、HEIC、DNG（没有配对 RAW）：Lightroom 读这几种格式时看文件内部，不看旁路文件。设置里提供「写入文件内元数据」，默认关闭。开启后只改元数据，不重新编码图像。某种格式在 iOS 上做不到不重编码的写入，该格式的选项就置灰并说明原因。
7. 只有写入确认成功后，才把该张该次修改记为已保存。写入中、失败、尚未确认的修改，都不能显示成「已写入」。
8. 写失败时保留用户刚才做的选择，供重试。重试成功前，不把它当成已经保存。
9. 尽量保全文件里原有的、Clove 并不认识的其他信息，避免为了写一个星级而丢掉别的软件留下的数据。
10. 色标在 XMP 里写固定英文名，不随界面语言变化。默认 5 色是 Red、Yellow、Green、Blue、Purple。

### 失败与恢复

下面的用户可见句子是建议文案，不是已批准文案。含义需要准确。只读和空间不足必须分开说，不能并成一句让人猜。数量用占位，不写死某次看到的张数。

| 情况 | 建议文案 | 用户可以做什么 | 界面不得出现的状态 |
| --- | --- | --- | --- |
| 单张写入失败 | 这张的标记没写上。要再试一次吗？ | 再试一次；取消 | 先显示已写入，再悄悄变回未保存 |
| 这个文件夹的访问权限没了 | 这个文件夹的访问权限没了。请重新打开一次。 | 重新打开该文件夹 | 继续显示能写，实际写不进去 |
| 找不到记住的位置 | 找不到这个位置了。请从「打开」重新选一次。 | 从「打开文件夹」再选 | 点「最近打开」后没有任何说明 |
| 位置只读，或存储本身不允许写入 | 这个位置现在只能看，不能写入标记。 | 取消，或在可写位置重新打开 | 和「空间不够」混成一句 |
| 位置没有足够空间 | 这个位置空间不够，标记写不进去。 | 腾出空间后再试 | 和「只能看」混成一句 |
| 外置盘在使用中断开 | 磁盘断开了。请重新接上，再打开这个文件夹。 | 接上后再打开 | 仍显示正在写入或已经写好 |
| 批量写入部分失败 | 写好了 N 张，还有 M 张没写上。 | 重试没写上的；取消 | 把整批显示成全部成功或全部失败 |
| 整理拒绝片部分失败 | 已移动 N 张，还有 M 张没移动。 | 重试没移动的；取消 | 把没移动的照片从网格里隐藏 |
| 用户关闭页面或离开目录时，还有未确认的写入 | 还有标记没写完。 | 等写完再离开；仍然离开 | 离开后把未确认的修改显示成已保存 |

## 智能分组与手工标记

手工标记是唯一的事实。相似组只负责分组。

- 分组和「再跑一次」都不会写入或改动任何标记。
- 组内的一键收尾是用户主动执行的操作，并且永远不会拒绝已有星级或色标的照片。
- 用户关掉相似组后，主路径完整可用。
- 不把准确率、召回率或「接近竞品」写成首发承诺。

## 浅色、深色与易用

- 所有主屏同时有浅色和深色，并跟随系统外观。Duo 与其他设备用同一套结构，不另做深色皮肤。
- 使用系统导航栏、工具栏、列表、按钮和系统色，以便跟随系统对比度和常规辅助功能。
- 按幅度打星对部分用户不方便，星级条和键盘必须能完成所有标记操作，并支持 VoiceOver。
- 不在本文承诺具体对比度数值或尚未写明的朗读文案。需要补的是各状态和报错的准确、非技术说法，见上表。

## 打开哪些文件

产品锁定的范围是：打开文件夹后扫描 JPEG、HEIC 和主流 RAW（含 DNG）。RAW 是首要场景。首发不做自研 RAW 解码。

可以依据的公开事实，而不是 Clove 自己测过的保证名单：

- 网格和详情预览应优先走系统图像能力。工程结论建议网格先用嵌入预览，详情在需要看清时再做完整 RAW 处理。双击放大到 100% 时，先放大嵌入预览，必要时再解码完整 RAW。见[工程调研来源](https://app.notion.com/p/41237873fb548107bd96d0f6838b1200)。
- Apple 公布过 iOS 相机 RAW 支持机型，工程调研引用的是 [iOS 18 支持页（页面标注 2025-07）](https://support.apple.com/en-us/120534)。名单随系统更新变化。未列入的机型，Apple 仍为 DNG 提供基础支持。部分机型只支持未压缩、无损或单拍 RAW。
- 因此，Clove 的产品承诺是：打开系统能够生成预览的 JPEG、HEIC 和主流 RAW。具体能打开哪家相机的哪一种压缩格式，以用户设备上的系统支持为准。本文不另列一份保证机型表。
- DNG（如 iPhone ProRAW、徕卡、宾得）按 RAW 显示，但写标记时归入「单独的 JPEG、HEIC、DNG」一类，见「标记如何落盘」第 6 条。
- 打不开、或不支持的压缩格式，必须有可见说明，不能用空白图冒充已经加载。
- 典型目录有多大、预览要多快、详情解码要多快，都还没有写入产品定稿的数字。任何耗时或张数目标都只能标成待实测，不能写成首发承诺。

首发不提供系统照片图库入口。若以后要加，也不能变成只在临时会话里看图、不写 XMP 的流程，需要单独决定。

## 隐私与离线

- 主路径是对着用户自己的文件夹工作。标记写在该文件夹的 XMP 里。
- 相似组分析在设备上完成。首发不做联网云端 AI，也不做 CloudKit 或备份同步。
- 无网络时，用户必须仍能打开有权限的文件夹、浏览、打标、写入 XMP 和整理拒绝片。
- 旧工程结论未发现 siftapp 依赖应用云服务。Clove 首发也不引入把原片上传到自家服务器这件事。
- 本文不代替正式隐私政策文本。

## 工程约束（不是产品范围本身）

- 整理拒绝片必须是同卷移动，每个文件的成功与失败单独确认。
- Duo 布局按实际可用空间变化，不要按设备类型写死两套互不相通的界面。半折时避开折缝。
- 保存成功必须能按文件、按这一次修改确认。不能在尚未确认时把界面画成已保存。
