# Browsing action contracts

Generated by `.agents/skills/browsing-workflow/scripts/check --actions-only` from
`model/action-contracts.json` and successful full-depth action witness queries.
Copy `.build/formal-verification/action-coverage.md` here after an intentional inventory update.

Each action has an independent pre-state/request effect check in addition to the existing
safety invariants. This is an immediate transition contract, not liveness. The observer's
raw pre-state snapshot and request capture are trusted; the mutated assignments never supply
the expected post-state. Shared pure domain rules remain model assumptions reviewed against Swift.

All rows inherit depth 12. Mark and Undo require FIFO space (total capacity two). Close/Open/
Reconnect cover drained transitions only. System write rows cover successful rating-only actions.
`Init` fixes the small world's initial unmarked data; it is an initial predicate, not a Next action.

## Reachability conditions

Each query adds `NoActionWitness` after every normal safety and effect invariant.
Only its intentional violation counts as an enabled-action witness. A tool error,
another invariant violation, or an exhausted queue without reaching the action fails the check.
No mutation is credited merely because it disables an action. The extra boundary mutants
admit an invalid outward request; outcome mutants execute with incorrect assignments.
